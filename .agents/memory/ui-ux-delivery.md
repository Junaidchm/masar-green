---
name: UI/UX delivery scope
description: How to interpret requests to improve the existing Masar Green interface.
---

For Masar Green UI/UX improvement requests, deliver changes in the working web app unless the user explicitly requests concepts, alternatives, or canvas-only work.

**Why:** The user repeated the request for a great UI/UX for the web app after receiving canvas previews rather than improvements to the working app.

**How to apply:** Reuse existing design work as a starting point, preserve functional app behavior, and verify the actual app. Do not treat a canvas-only concept as completion of an app improvement request.
